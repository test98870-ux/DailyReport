수집·정리 기준

한국 시간 기준입니다. 이 시각 이전에 발행된 자료는 읽음 여부와 관계없이 정리합니다. 보관함 자료는 유지합니다. 날짜만 있는 리포트·공시는 해당 날짜 0시로 판단합니다.

자동 정리

앱을 열거나 돌아올 때, 수집 후, 설정 저장 시 정리합니다. 정리한 목록과 본문은 삭제하고 재등록 방지 기록만 남깁니다. 기간을 다시 넓혀도 이미 정리한 자료는 돌아오지 않습니다. 앱을 삭제하거나 데이터를 초기화하면 정리 기록도 삭제됩니다.

수집할 소스

OpenDART 공시

인증키 없이도 다른 소스는 수집할 수 있습니다.

AI 키가 아닌 공시 조회용 키입니다. 키는 앱 내부 저장소에 보관되며 목록 화면에 표시하지 않습니다.

앱을 벗어나면 수집이 중단됩니다. 이미 전송한 요청은 응답 또는 시간 제한 후 종료됩니다. 앱 삭제 시 저장 자료와 읽음 표시도 삭제됩니다.
